# Kaneo chess pieces

These 12 standard chess-piece SVGs are the Kaneo set by Kadagaden. The set is
inspired by Chess.com's Neo pieces, but it is independently distributed under
CC BY 4.0 rather than copied from Chess.com.

- Source: https://github.com/Kadagaden/chess-pieces
- Pinned source commit: `b035b0cc6a68e9fb99c872c8fe073c3ae3eba8a0`
- Source directory: `chess_kaneo`
- License: CC BY 4.0; the complete upstream license is included as `LICENSE.txt`

The SVG files and license are kept byte-for-byte identical to that pinned
source. Styling and sizing are applied by the Play application rather than by
modifying the artwork.
